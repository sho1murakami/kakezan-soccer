# がくしゅうアプリ ⚽

9さい向けの かけ算・漢字・地理のアプリです（5さい向けの「さんすうアプリ」をもとにしています）。iPad の Safari で使う想定の、HTML 1枚だけのWebアプリです。

## できること

### メニューの構成

- トップ画面には「さんすう」「こくご」「りか」「しゃかい」の4教科が横に並び、画面の下に小さく「ゲーム」があります
- 教科を押すと、その教科の項目が出ます：さんすう＝かけざん、こくご＝かんじ かきとり・かんじ よみ、しゃかい＝とどうふけん。りかは準備中のため、グレーで押せません
- おうちの方へ画面の「📚 メニューに出す項目」で、項目ごとに表示・非表示を選べます。項目がひとつもない教科はグレーになります。かけざん（またはかんじの両方）を出さないときは、ゲーム・とどうふけんのカギでその教科のシールを数えません

### かけざん

- **かけざん**：1回7問。「2けた × 2けた」と「3けた × 2けた」が3問と4問（どちらが4問かは毎回ちがいます）、ばらばらの順に出ます（一の位が0の数は出ません）
- **けってい ボタン**：数字ボタンを押しただけでは答えになりません。「けってい」を押すと答え合わせをします。ハードウェアキーボードでは Enter が「けってい」です
- **けいさんメモ**：問題の横に、指や Apple Pencil で筆算を書けるメモ欄があります。次の問題で自動で消えます（おうちの方へ画面で非表示にもできます）
- **まちがえたとき**：1回目は「もう一回」。2回目もまちがえると答えを表示し、「つぎへ」を押すまで待ちます。結果画面では、まちがえた問題と答えを一覧で見られます
- **ごほうび**：正解でゴール演出、7問中5問以上を1回目で正解するとシール1枚。シールは全100種類。グレードは ノーマル（78種類）・レア（16種類）・スーパーレア（6種類）で、どのシールも12%でキラキラになります。まだ持っていないシールは2.5倍出やすくなります。シールちょうの「🎲 でる かくりつ」で、今の出現確率を見られます

### かんじテスト（中学受験向け）

- **レベル**：3年・4年・5年・6年から選びます。学年別漢字配当表（2020年度〜）にそって、答えの漢字にその学年の字が必ず入ります（すべてオリジナルの文。――線以外の文は3年までの漢字だけ）
- **かきとり**：入試と同じく、短い文の――線のカタカナを漢字で書きます（送りがなは書きません）。熟語・同音異義語・同訓異字を多めにしています。各学年の配当漢字は、すべてどれかの問題の答えに入っています（3年169問・4年170問・5年170問・6年178問）
- **よみ**：――線の漢字の読みを答えます（送りがなは入れません）。はじめは「キーボード」で、問題が出たときから答えの欄に入力できる状態になります（iPad のキーボード・ローマ字入力も可、Enter で答え合わせ）。画面の50音ボタン（゛゜小 つき）にも切り替えられます。日本語キーボードで勝手に漢字に変わるときは、iPad の「設定」→「一般」→「キーボード」→「ライブ変換」をオフにしてください（漢字に変わってしまったときは、アプリが変換前のひらがなに戻します）。訓読み・熟語・特別な読み（景色・迷子・砂利 など）。各学年の配当漢字がすべて、どれかの問題に入っています（3年190問・4年178問・5年177問・6年176問）
- **チャレンジ1〜4**：小学校で習わない常用漢字（中学で習う1110字）を、新聞でよく使われる順に4つに分けたレベル（1がよく使う字、4があまり使わない字）。かきとり・よみとも、1110字がすべてどれかの問題に入っています。難関校の入試で出やすい言葉を優先していますが、実際の過去問と照らし合わせたものではありません
- **かきじゅん**：かきとりで答えたあと（正解・不正解とも）、正しい書き順を大きくアニメーションで表示します（はじめは速く、「もう一回 みる」はゆっくり）。右側に、その漢字の部首・画数・音読み・訓読み・意味を表で表示します（2字以上の答えは、字をタップして切り替え）。「かんじの きろく」の字をタップしても同じ画面が開きます。書き順のデータは [KanjiVG](http://kanjivg.tagaini.net)（© Ulrich Apel, CC BY-SA 3.0）を jsDelivr から読み込みます
- **わからない ボタン**：答えを見て次へ進めます（不正解として数え、次の回に出やすくなります）
- **手書き＋自動判定（かきとり）**：マスに指や Apple Pencil で書き、「けってい」で判定します。判定には Google の手書き文字認識を使い、書いた線の形（座標）だけを送ります。読み取った字の上位3つまでに正解があり、それより上にほかの漢字がなければ正解です。とめ・はね・書き順までは判定できません
- **4択**：電波が戻ったら「✍️ てがきに もどす」を押すと、次の問題から手書きの判定に戻ります。ネットにつながらないときは自動で4択（にた形の漢字・同じ読みの漢字から）に切り替わります。おうちの方へ画面で、いつも4択にもできます
- **ルール**：1回7問。まちがえた問題は次の回に2問まで出ます。シールのルールはかけざんと同じです

- **かんじの きろく**：レベル選びの画面の「📊 かんじの きろく」で、かきとり・よみ別に、レベルごとの「おぼえた字／やった字／全部の字」をグラフで見られます。行をタップすると、そのレベルの字が色分けで一覧になります（緑＝おぼえた、黄＝やった、灰＝まだ）。各レベルのボタンにも進み具合を表示します
  - 「おぼえた」の決め方：その字が入った問題に、**ちがう日に3回、1回目で正解**すること。とちゅうで1回でもまちがえる（2回目で正解・わからない も含む）と、また0から数えます
  - 「やった」：その字が入った問題に1回以上答えたこと

- **出題の優先**：まだ覚えていない漢字（まだやっていない字・やったけれど覚えていない字）が入った問題を優先して出します。全部覚えた問題はまれにしか出ません
- **きょうのミッション**：おうちの方へ画面で選んだ「優先するレベル」（はじめは3年）のシールをその日に5枚集めるまで、ほかのレベルではシールがもらえません（練習はできます）。「優先しない」も選べます

### とどうふけん（しゃかい）

- 日本地図の1つの都道府県が赤く光ります（小さい県は赤い丸でかこみます）。その名前を4つの中から選び、「けってい」で答えます。選ぶ名前には読みがなが付いています。まちがえる候補は、同じ地方の県が出やすくなっています
- 1回目でまちがえると「もう一回」、2回目もまちがえると（または「わからない」で）答えを地図と名前で見せます
- 1回7問、4問以上を1回目で正解するとシール1枚。シールは1日5枚まで（それ以上も遊べますが、シールはもらえません）。どちらもおうちの方へ画面で変えられます
- その日に「かけざん」と「かんじ」のシールを5枚ずつ集めるまで、ちりはできません（おうちの方へ画面でオフにできます）
- まだ覚えていない都道府県を優先して出し、まちがえた都道府県は次の回に2問まで出ます。「覚えた」の決め方は漢字と同じ（ちがう日に3回、1回目で正解）で、トップ画面のカードに「おぼえた ○ / 47」を表示します
- 沖縄県は地図の左上の枠の中に、少し大きくして表示しています。東京都の伊豆・小笠原諸島、鹿児島県の奄美群島、沖縄県の大東諸島などは省いています。地図のデータは [Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）の行政区画を簡単にしたものです（chiri-data.js）

### ゲーム

- トップ画面の「ゲーム」から、めいろ・すうどく と むずかしさを選びます
- **めいろ**：1 → 2 → 3 … の順に、すべてのマスを1回ずつ通って最後の数字までつなぐパズル。指でなぞります。やさしい（5×5）・ふつう（6×6・かべあり）・むずかしい（7×7・かべあり）。遊ぶたびに新しい問題を自動で作ります
- **すうどく**：6×6（ふとい枠は2×3）。メモ・もどす・ヒント（1回3つまで）つき。答えが1通りになる問題を自動で作ります。やさしい（最初の数字18こ）・ふつう（14こ）・むずかしい（11こ）
- その日に「かけざん」と「かんじ」のシールを5枚ずつ集めるまで遊べません（おうちの方へ画面でオフにできます）
- クリアするとコイン1枚。コイン10枚で、トップ画面の「🪙」ボタンを押すとシール1枚（ランダム）と交換できます（自動では交換しません）。おうちの方へ画面でコインをオフにできます。むずかしさごとにベストタイムを記録します

### きょうつう

- **デザインテーマ**：おうちの方へ画面で「サッカー」「ノーマル」「かわいい」から選べます。画面の色・もよう、正解の演出と効果音、ランクの名前が変わります。「かわいい」では、もらえるシールも女の子向けの100種類（スイーツ・お花・どうぶつ・おひめさま・おしゃれ など）になり、ずかんと出る確率もそのシールで表示します（それまでに集めたシールや記録はそのまま）
- **ランク**：シールの枚数（0・45・120・240・390・600・900枚）であがります。名前はテーマごとにちがいます
  - サッカー：ルーキー → レギュラー → エース → キャプテン → スター → レジェンド → ワールドクラス
  - ノーマル：みならい → がんばりや → ものしり → はかせ → めいじん → たつじん → でんせつ
  - かわいい：たね → つぼみ → おはな → ようせい → おひめさま → じょおうさま → ミラクルスター
- **出題数とシールの基準**：おうちの方へ画面で、かけざん・かんじテスト・ちり それぞれの「1回の問題数」と「シールがもらえる正解数」を変えられます（はじめは かけざん・かんじ 7問中5問、ちり 7問中4問）。1日にもらえるシールの上限も、それぞれ設定できます（はじめは かけざん・かんじ 上限なし、ちり 5枚）。上限をこえても練習はできますが、シールはもらえません（コインとの交換のシールは数えません）。上限が5枚より少ないときは、ちり・ゲームのカギは上限の枚数で開きます
- **にがて対策**：まちがえた問題を覚えておき（最大20問）、次の回に2問まで出します。1回目で正解すると一覧から消えます
- **おうちの方へ画面のロック**：「1700 の 15%」のような割合の計算を答えます（9さいではまだ習わない計算です）

## 公開のしかた（GitHub Pages）

1. このフォルダを GitHub のリポジトリに push する
2. リポジトリの Settings → Pages → Branch を `main` / `/ (root)` にして Save
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で開けます

iPad の Safari で開いたら、共有ボタン →「ホーム画面に追加」がおすすめです。

## 漢字の基本情報について

`kanji-info.js` に常用漢字2136字の部首・音読み・訓読み・意味を入れています。読みは常用漢字表の読みで、KANJIDIC のデータと照らし合わせて確かめています（KANJIDIC にない常用の読み：中のジュウ、曽のゾ、速のはや-まる など数件は手で確かめて入れています）。部首は辞典によって違うことがあります。意味は小学生向けに短く書いたものです。

## 記録の引っこし（バックアップ）

ホーム画面のアイコンは、アイコンごとに記録が別々に保存され、アイコンを削除すると記録も消えます。アイコンを作り直すときは「おうちの方へ」画面の「記録のバックアップ」で引っこしてください。

1. 今のアイコンで開き、「コピー」（または「ファイルに保存」）
2. Safari でアプリを開き、共有ボタン →「ホーム画面に追加」で新しいアイコンを作る
3. 新しいアイコンで開き、「はりつけ」（または「ファイルから」）→「読み込む」
4. 新しいアイコンでシールが戻ったのを確かめてから、古いアイコンを削除

## 記録について

シールや設定はその iPad の Safari の中（localStorage）に保存されます。5さい向けの「さんすうアプリ」とは別の記録です。サーバーには何も送りません。
